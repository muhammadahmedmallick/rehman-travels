================================================================================
                           🚀 QUICK START (7 STEPS)
================================================================================

1️⃣  Install dependencies
    $ cd backen-alrehman
    $ pip install -r requirements.txt

2️⃣  Generate migrations for new mobile app
    $ python manage.py makemigrations mobile

3️⃣  Apply migrations to PostgreSQL
    $ python manage.py migrate --database=default

4️⃣  Fake legacy migrations (MySQL is read-only)
    $ python manage.py migrate --database=legacy --fake

5️⃣  Create Django admin user
    $ python manage.py createsuperuser

6️⃣  Start all services
    $ docker-compose up -d

7️⃣  Run tests to verify setup
    $ python manage.py test apps.mobile

Expected time: 20-30 minutes total

================================================================================
                         ⚠️  IMPORTANT NOTES
================================================================================

1. Database Router
   The database router automatically routes:
   - Legacy models → MySQL (read-only)
   - New models → PostgreSQL (read/write)

2. Migrations
   - Only migrate to PostgreSQL (default)
   - Never run migrations on legacy database
   - Use --fake for legacy migrations

3. Read-Only Enforcement
   Three layers of protection prevent accidental writes to MySQL:
   • Django router returns None for writes
   • Database user permissions (optional)
   • Admin interface restrictions

4. Docker Services
   All services must be running:
   - MySQL (for legacy data)
   - PostgreSQL (for new data)
   - Redis (for caching/sessions)
   - Django Web (your API)

5. Environment Variables
   Ensure .env has both database configurations:
   - LEGACY_DB_* variables for MySQL
   - DJANGO_DB_* variables for PostgreSQL
