================================================================================
                      HOW TO DEPLOY TO EC2
================================================================================

ONE-COMMAND DEPLOYMENT:

1. SSH into your EC2 instance:
   ssh ubuntu@YOUR-EC2-IP

2. Clone the repository:
   cd /home/ubuntu
   git clone YOUR-REPO-URL rehman-travels
   cd rehman-travels/backen-alrehman

3. Run deployment script:
   sudo ./deploy.sh

That's it! The script will:
- Install Docker and Docker Compose
- Build all Docker images
- Start all 8 services
- Run database migrations
- Display access URLs

⏱️ Deployment time: 5-10 minutes

================================================================================
                           TROUBLESHOOTING
================================================================================

ISSUE: Can't access website
FIX:
  • Check EC2 Security Group allows port 80
  • Verify nginx is running: docker-compose ps nginx
  • Check logs: docker-compose logs nginx

ISSUE: React CMS shows blank page
FIX:
  • Check CMS container: docker-compose logs cms
  • Verify build completed: docker-compose ps cms
  • Restart: docker-compose restart cms

ISSUE: API returns 500 error
FIX:
  • Check Django logs: docker-compose logs web
  • Verify migrations: docker-compose exec web python manage.py showmigrations
  • Check database connection: docker-compose ps postgres db

ISSUE: Docker build fails
FIX:
  • Clean up: docker system prune -a
  • Rebuild: sudo ./deploy.sh
  • Check disk space: df -h

ISSUE: Services won't start
FIX:
  • Check health: docker-compose ps
  • View startup logs: docker-compose logs --tail=50
  • Restart individually: docker-compose restart SERVICE_NAME

ISSUE: Permission denied on scripts
FIX:
  chmod +x deploy.sh update.sh
